Pick the guide for your project. Each ZIP from [GitHub Releases](https://github.com/mateo-m/kotoba/releases) already includes the matching adapter in `kotoba/boot.rb`.

| Guide | Project |
| --- | --- |
| [Bare RGSS](/v0.1.0/integration/bare-rgss) | Plain RPG Maker XP |
| [Pokemon Essentials](/v0.1.0/integration/pokemon-essentials) | Essentials v16–v21 or BES |
| [Essentials migration](/v0.1.0/integration/pokemon-essentials-migration) | Moving `_INTL` strings into catalogs |
| [Third-party adapters](/v0.1.0/integration/third-party) | Custom engine or fork |

Do not copy adapter files from this repo by hand. Use a release ZIP or follow the third-party guide to register your own adapter.
